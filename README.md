# CTF Writeups

Solutions and notes from CTF challenges I work through — mainly
[picoCTF](https://picoctf.org/) / picoGym and CyLab Academy.

Each writeup records the path I actually took, not a cleaned-up version of it.
The approaches that failed are kept in place, next to the step where they failed,
because those are the parts worth reading — a solution that goes straight to the
answer teaches the answer, and nothing else.

I mainly focus on doing the CTF:s, give a run down of what succeeded and what failed and instruct claude to add to the list of writeups, so I can focus on doing as many as possible!

My profile(s): https://learn.cylabacademy.org/users/xxtentacion

## Writing one

See [WORKFLOW.md](WORKFLOW.md) for the full loop. In short:

```bash
./scripts/new-challenge.sh picogym cryptography "Basic Mod 1"
# solve, dumping everything into notes.md as you go
# turn notes.md into README.md, then set status: published
python3 scripts/update_index.py
git add -A && git commit -m "writeup: Basic Mod 1" && git push
```

[templates/example.md](templates/example.md) is a complete worked example,
including how dead ends are recorded.

## A note on what gets published

picoGym is a permanent practice set and writeups for it are uncontroversial.
**Live competitions are different** — most, picoCTF included, prohibit sharing
solutions or flags while scoring is open. Before publishing anything from a
running event or a graded course, check that event's rules. Keeping a writeup as
`status: draft` holds it out of the index, but it is still in the repo and still
public once pushed; if in doubt, don't commit it yet.
